# SkillProof Learning Platform

A competitive learning platform with real-time interaction
and blockchain-based digital certificate verification.

## Technology

### Frontend
- React
- TypeScript
- Vite

### Backend
- Java 21.0.11
- Spring Boot 4.1.1
- Maven 3.9.16

### Infrastructure
- PostgreSQL
- Redis
- Docker Compose

### Realtime
- WebSocket
- STOMP

### Blockchain
- Solidity
- Hardhat
- OpenZeppelin

## Main Features

- Identity & Organization Management
- Learning Path & Learning Progress
- Quiz & Assessment
- Real-Time Interactive Challenge
- Certification
- Blockchain-based Certificate Verification
- Community & Marketplace
- Recommendation
